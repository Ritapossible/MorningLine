Basescan needs an Etherscan account to verify through its API, so it is done once by hand in
the browser with the files in this folder. They were downloaded from Sourcify, so they are the
exact compiler input that already matched the deployed bytecode.

## Steps, once per contract (on a computer)

1. Open `https://sepolia.basescan.org/address/<address>#code` and click **Verify and Publish**.
2. Fill in:
   - Compiler type: **Solidity (Standard-Json-Input)**
   - Compiler version: **v0.8.28+commit.7893614a**
   - License: **MIT**
3. Continue. Upload the standard input file for the contract:

   | Contract | File | Constructor arguments |
   |---|---|---|
   | MorningLine v2, demo | `MorningLine.standard-input.json` | paste `MorningLine-demo.constructor-args.txt` |
   | MorningLine v2, production | `MorningLine.standard-input.json` | paste `MorningLine-production.constructor-args.txt` |
   | LINE | `LineToken.standard-input.json` | leave empty |
   | Demo USDC | `DemoUSDC.standard-input.json` | leave empty |

4. Pass the captcha and **Verify and Publish**. Basescan shows "Successfully generated Bytecode
   and ABI" and a green check on the Contract tab.

With an Etherscan API key the same is one command:
`ETHERSCAN_API_KEY=... npx hardhat verify etherscan --network baseSepolia <address> <args>`.
